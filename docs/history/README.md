# 历史与考古（不随仓库发布）

v2 是**断代重写**，刻意**不带** v1 的历史沉淀：

- v1 的逐次改动注释、内嵌测试夹具、逐芽考古、讨论记录，都不进 v2 仓库。
  理由见 `docs/versioning.md`：新旧规则叠加本身就是 v1 打转的病根。
- 需要知道「某个设计为什么是这样」时，答案在 `docs/mechanism.md` 的「为什么」小节里；
  那是**精炼后的理由**，不是当时的对话记录。
- 已退役的机制不靠「考古」找回，靠 `docs/superseded.md` 的**废弃登记表**：
  旧机制 → 取代者 → 残留状态，一条一行。

## 什么时候该往这个目录写东西

只有一种情况：**某个决定只有在知道「当时为什么不这么做」时才不会被误改**。
那就写一个短文件，格式固定：

```
# <决定>（<日期>）
- 当时的选项：
- 选了哪个、为什么：
- 什么条件下应该重新考虑：
```

除此之外，历史记录留在版本控制里（`git log`）就够了——**账本只收事实，不收情绪**。
