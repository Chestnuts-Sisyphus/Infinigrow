> 用途：**退役机制不许「悄悄消失」，也不许「悄悄活着」。**
> 每一条退役件都在这里登记：旧机制 → 取代者 → 残留位置 → 清理状态。
> 清查判据：`python -m infinigrow scan`（R3 专门盯提示词里的旧条款回归）。

v1 的原始残留不在本表管辖范围（v1 整体封存，见 `docs/zh/versioning.md`）。

## 新增退役件的流程

1. 在本表**加一行**（不要删旧行——退役史也是账）；
2. 在代码/提示词里移除该机制（或标注为历史说明，且不得再出现在机制语言位置）；
3. 跑 `python -m infinigrow scan` 与 `pytest`：绿了才算清完；
4. 如果退役件是**判据级**的（改公设），同时改 `docs/zh/mechanism.md` 与提示词。
